# Digital Playground

A responsive, GitHub Pages-ready collection of original browser mini-games.

## Included
- Reaction Sprint: wait for the signal, then react quickly.
- Target Rush: tap as many moving targets as possible before time runs out.
- Memory Tiles: repeat an increasingly long sequence.
- Local best scores, difficulty selection, help dialog, keyboard/touch support and sound toggle.
- No backend, accounts, payment, or external dependencies.

## Run locally
Open `index.html` in a modern browser, or serve the folder with any static file server.

## GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

This project uses original code, interface copy, and CSS visuals. It is an independent homage to common browser-game patterns, not an official copy of any third-party site.
