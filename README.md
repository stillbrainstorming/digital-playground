# Digital Tapli 👋

> A playful, interactive browser & mobile tapli game for instant stress relief.

An authentic web recreation of [digitapli.com](https://digitapli.com), built as an installable Progressive Web App (PWA) ready for GitHub Pages.

## ✨ Experience

- **Swipe to Tapli** — Intuitive left-swipe gestures trigger crisp animations and reactive squish physics.
- **Dynamic Word Bursts & Floaters** — Multilingual pop effects (*TAPLI!*, *धड़ाम!*, *BOOM!*, *झन्नाट!*) at the exact point of contact.
- **Combo System & Milestones** — Rapid-fire taplis ignite an active combo counter with ascending melodic audio rewards.
- **Audio Slap Synthesis** — Real-time Web Audio API synthesized impact effects without needing external sound files.
- **Counters & Persistence** — Local taplis saved safely in browser storage, plus a simulated community worldwide counter.
- **Social Sharing** — One-tap sharing to WhatsApp and clipboard copy for friendly score competitions.
- **PWA & Offline Capable** — Install directly as a mobile app from browser links with fast offline caching.

## 🚀 Deployment to GitHub Pages

1. In your GitHub repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Source** as `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your PWA will be published at `https://<username>.github.io/<repo-name>/`.

## 📱 Mobile App (PWA) Usage

- **Android (Chrome)**: Tap the menu (⋮) → **Install app** or **Add to Home screen**.
- **iOS (Safari)**: Tap the Share button (⎋) → **Add to Home Screen**.
- Enjoy a full-screen, native-like experience directly from your home screen.

## 📜 Disclaimer

This is a lighthearted stress-relief game created for fun and entertainment. In Indian cultural context, a playful tapli is an affectionate, humorous gesture among peers. No real individuals are depicted.
